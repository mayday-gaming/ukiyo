# Ukiyo

Il mercato fluttuante: un gioco d'aste zen e infinito, in stile stampa giapponese.

Ogni oggetto arriva su una zattera sotto la luna. Ispezionalo per restringere la perizia, poi sfida tre rivali all'asta. Alla fine il valore reale decide: **Cash** o **Trash**.

- **Quiete**: martello lento, tempo per respirare.
- **Marea**: lotti più ricchi, più copie, martello rapido.

Tasti: `Spazio` offri · `I` ispeziona · `J` rilancio deciso · `P` passo.

Gioca: https://mayday-gaming.github.io/ukiyo/

Un solo file `index.html`, nessuna dipendenza.
